# 95. 학술 서술 규칙 — 판넬 · 브로셔 · 논문용 글

> **적용 범위** — 이 규칙은 **대외 글**에만 건다: 전시 판넬, 브로셔, 판넬에 실리는 그림의
> 글자, 최종 보고서(논문) 원고. 내부 기록(`20`~`24`, `91_report.md` 등)은 「나에게 설명하는
> 글」이라 지금 문체를 유지한다(`19_record_keeping.md` §9). 두 문체를 한 문서에 섞지 않는다.
>
> **검사** — `python scripts/check_academic_style.py`. 금지 표현의 **전체 목록은 그 스크립트의
> `LEXICON` 이 유일한 원천**이고 `--lexicon` 으로 표를 출력한다. 이 문서는 원칙과 대표 예만
> 싣는다(같은 목록을 두 곳에 두면 한쪽이 낡는다 — O-27). 근거 결정은 D-43.
>
> **화면(GUI) 글** — 시연 화면의 라벨 · 버튼 · 상태값 · 툴팁은 이 규칙 위에 화면 규칙 U1~U8 을 더한
> `docs/39_ui_copy_style.md` 를 따른다(D-43 보완 4). 발표 자료(PPT)는 이 문서를 그대로 따른다.

## 1. 출발점 — 지적된 세 표현과 그 원인

| 지적된 표현 | 무엇이 문제인가 | 일반화한 원인 | 규칙 |
|---|---|---|---|
| 「심박 모양 가짜」 | 영어(spurious beat)를 낱말 단위로 옮긴 **조어**다. 학계에 없는 말이라 독자가 정의를 추측해야 한다 | 확립된 학술 용어를 찾지 않고 설명어를 이어 붙여 이름을 만들었다 | **A1** |
| 「없는 자리에 깨끗한 심박을 그린다」 | 알고리즘을 사람처럼 쓴 **의인화**(「그린다」)와 **감각어**(「깨끗한」), 구어 명사(「자리」)가 겹쳤다 | 현상을 비유로 설명하던 내부 문체가 그대로 대외 글에 들어왔다 | **B1 · B2** |
| 「튜닝 hard, QRS 끔」 | 설명한 적 없는 설정명을 그대로 적었다. 독자는 hard 가 무엇인지, QRS 를 왜 끄는지 알 수 없다 | 코드의 설정값을 **의미로 옮기지 않고** 옮겨 적었다 | **C1 · C2** |

세 지적은 서로 다른 층의 문제다 — **용어**(무엇이라 부르나), **서술어**(무엇을 한다고 쓰나),
**정의**(처음 보는 사람이 따라올 수 있나). 아래 규칙도 이 세 층에 문장 구조 · 수치 표기 ·
그림 글을 더한 여섯 묶음이다.

## 2. 규칙

### A. 용어 — 무엇이라 부르나

| | 규칙 | 예 (전 → 후) |
|---|---|---|
| **A1** | **확립된 학술 용어를 쓴다.** 우선순위: ① 해당 분야의 표준 한국어 학술어(의학 · 전자공학 용어집) ② 한자어 학술어에 첫 등장 시 영문 병기 ③ 원어 음차. 설명어를 이어 붙여 새 이름을 만들지 않는다 | 심박 모양 가짜 → **가성 QRS군(spurious QRS complex)** · 가짜 검출 → **위양성 검출(false positive)** · 없는 파형을 만든다 → **가성 파형 생성** |
| **A2** | 첫 등장은 **「한국어 용어(영문, 약어)」**, 이후는 한국어 또는 약어만 | 정상 웨이블릿 변환(stationary wavelet transform, SWT) → 이후 SWT |
| **A3** | **한 개념에 한 용어.** 같은 대상을 여러 이름으로 부르지 않는다 | front-end · FE · 전처리 → **공통 전처리** 하나 |
| **A6** | **용어는 출처로 확인한다.** 기술 용어는 쓰기 전에 한국어 학술 자료(교재 · KCI/KoreaScience 논문 · 학회 용어집 · TTA 정보통신용어사전)에서 실제 쓰는 형태를 찾아 §3.1 에 출처와 함께 적는다. 정착된 한국어 형태를 찾지 못하면 **원어**를 쓴다(필요하면 기능 서술을 괄호로). 낱말을 직역해 만든 말은 A1 위반이다 | feature map → 「특징 지도」(조어, 사용 사례 없음) ✗ → **특징 맵 · 특성 맵 · feature map** / dilated convolution → 정착 번역어 미확인 → **dilated convolution** |
| **A4** | **내부 식별자를 쓰지 않는다** — 기법 코드(M04), 손실 코드(L6), 데이터축(D1), 기록 번호(F-58), 실험 번호(EXP-C), 코드 변수(snr_imp_scaled). 꼭 필요하면 기호표를 한 번 두고 쓴다 | M05 → **확장 칼만 필터** · D1 → **MIT-BIH 실측 기록** · L6 → **무잡음 입력 보존항을 추가한 손실** |
| **A5** | **은유 · 별칭을 쓰지 않는다** | 같은 자 → **동일 평가 기준** · 조준 → **학습 목표의 설정** · 천장 → **상한** · 한 판 → **학습 1 회** |

### B. 서술어 · 표현 — 무엇을 한다고 쓰나

| | 규칙 | 예 (전 → 후) |
|---|---|---|
| **B1** | **의인화 동사를 쓰지 않는다.** 알고리즘은 그리거나 지우거나 건드리지 않는다 — 생성 · 제거 · 변형 · 추정한다 | 그린다 → **생성한다** · 지운다 → **제거한다** · 건드린다 → **변형한다** · 지어낸다 → **가성 파형을 생성한다** |
| **B2** | **구어 · 감각어 · 승부 은유를 쓰지 않는다** | 깨끗한 → **무잡음의** · 자리 → **위치 · 구간** · 몰린다 → **집중된다** · 이긴다 / 진다 → **우수하다 / 열등하다** · 손해 → **성능 저하** · 못 가림 → **통계적으로 유의한 차이가 관찰되지 않았다** |
| **B3** | **강조 수사를 쓰지 않는다** — 「」 · «» 인용 강조, 굵은 글씨, 줄표(—)로 잇는 구어 연결, 「A 가 아니라 B」 대조 반복 | 「A 가 아니라 B 다」 → **B 이다** (필요하면 A 는 별도 문장으로) |

### C. 정의 · 도입 — 처음 보는 사람이 따라올 수 있나

| | 규칙 | 예 |
|---|---|---|
| **C1** | **정의 없는 용어를 쓰지 않는다.** 처음 쓰는 기술 용어 · 설정명은 **기능 서술이 먼저, 용어는 괄호** | 「hard」 → **hard thresholding(임계값 이하 계수 제거)** · 「QRS 끔」 → **QRS 구간 임계값 완화 미적용** |
| **C2** | **지면 등급을 나눈다.** 판넬은 「기능 + 용어」의 최소형만 싣고, 풀이 · 근거는 **발표자 해설 노트**(`94_panel_plan.md` §10)와 보고서로 보낸다. 판넬에서 정의를 감당할 수 없는 용어는 판넬에 쓰지 않는다 | 판넬: 「hard thresholding(임계값 이하 계수 제거)」 / 해설 노트: hard · soft · garrote 의 차이와 데이터별 최적 설정 |
| **C3** | **설정값은 의미로 보고한다.** 값 나열이 아니라 「무엇을 하도록 설정했는가」 | 「튜닝 hard, QRS 끔」 → **실측 데이터에서는 임계값 이하 계수를 제거하고 QRS 구간 완화를 적용하지 않는 설정이 최적이었다** |

### D. 문장 구조

| | 규칙 |
|---|---|
| **D1** | **종결** — 본문은 학술 평서체(「-하였다」 「-이다」), 캡션은 「그림 n. 명사구. 요지 문장.」 구어 과거형 「-했다」는 「-하였다」로 |
| **D2** | **주어를 밝힌다.** 「우리」 대신 「본 연구」, 기법이 주어면 기법의 정식 명칭 |
| **D3** | **관찰과 해석을 가른다** — 관찰은 「-로 나타났다 · 관찰되었다」, 해석은 「-로 해석된다 · 시사한다」. 인과는 검증한 것만 단정한다 |
| **D4** | **두괄식** — 문단의 첫 문장이 요지, 근거와 수치가 뒤따른다. 한 문장에 한 명제 |

**D5 (2026-11-05)** — 판넬 · 브로셔 · 그림에 **의문문을 쓰지 않는다.** 연구 질문도 「~의 변화」 · 「~을 분석하였다」 처럼
서술형으로 적는다. 검사기 LEXICON `D5`(물음표)가 잡는다.

### E. 수치 · 통계

| | 규칙 |
|---|---|
| **E1** | 수치마다 **데이터 · 조건**을 붙인다(MIT-BIH, 입력 SNR −5 dB, 기록 22 개) |
| **E2** | 통계는 **검정 · 표본 수 · p 값**을 함께: 「(대응 t-검정, n = 4, p = 0.002)」. 「못 잼」 대신 「유의한 차이가 관찰되지 않았다(p = 0.15)」 |
| **E3** | 배수 비교는 **기준을 밝힌다**: 「SWT 대비 약 24 배」 |
| **E4** | 반올림 자릿수를 통일한다(dB 는 소수 첫째 자리). 음수는 문서에서는 −(U+2212), 그림 글자에서는 하이픈(글꼴 제약 — `tests/test_figure_text.py`) |

### F. 그림 안의 글

> **글자 크기 하한 (사용자 결정 2026-11-05)** — 그림 속 글자는 본문 대비 비율로 정한다.
>
> | 지면 | 본문 | 그림 속 글자 하한 |
> |---|---|---|
> | 브로셔 | 10 pt | **6 pt** (본문의 0.6 배) |
> | 판넬 | 18 pt | **13 pt** (지금 판넬 그림 수준 — 이 아래로 줄이지 않는다) |
>
> 크기에 맞춰 그림을 새로 그리기보다 이미 있는 그림을 줄여 쓰는 편이 정보를 덜 잃으면 그렇게 한다. 줄인 뒤의 크기(그린 pt ×
> 놓는 폭 / 그린 폭)가 하한 이상인지 확인한다.

| | 규칙 |
|---|---|
| **F1** | 그림 제목은 **내용을 기술하는 명사구**다. 결론 단정문(「칼만은 … 그린다」)은 캡션 · 본문으로 |
| **F2** | 축 · 범례는 **정식 명칭 + 단위**. 기법은 이름으로(코드 금지 — A4) |
| **F3** | 사례 그림은 **선정 기준을 그림에 적는다**(가장 뚜렷한 사례를 골랐다면 그렇게) |

## 3. 대응 어휘 — 이 과제에서 자주 쓰는 것

> **원어 유지 (F2, 사용자 판정)** — 학계 · 교재에서 원어나 음차로 쓰는 기술 용어(hard thresholding · window ·
> epoch · batch · seed · U-Net · 튜닝 · 체크포인트)는 번역하지 않는다. 정착 번역어가 없는 용어를 새로 옮기면 조어(A1)가 된다.
> 한국어로 바꾸는 것은 대응어가 분명한 일상어 대용 영어(clean → 무잡음, beat → 박동)뿐이다. 목록은 `scripts/style_rules.py` 의 `TERMS_KEEP`.

전체 금지 목록은 `python scripts/check_academic_style.py --lexicon`. 아래는 **대외 글에서 쓸
정식 용어**의 기준표다(A2 · A3 — 한 개념 한 용어).

| 개념 | 대외 글의 용어 (첫 등장 형태) | 내부 기록에서 쓰던 말 |
|---|---|---|
| 잡음 제거 전 공통 필터 | 공통 전처리(고역통과 0.5 Hz · 저역통과 100 Hz · 조건부 노치) | front-end, FE, `M_FE` |
| 정답 신호 | 기준 신호(reference) | 참값, 참조, clean |
| 합성 데이터 | 합성 ECG(McSharry 동역학 모델) | D0 |
| 실기록 데이터 | MIT-BIH 부정맥 데이터베이스와 NSTDB 실측 잡음 | D1 |
| SWT 기법 | 정상 웨이블릿 변환(SWT) 적응 임계값 처리 | M04, SWT thresholding |
| hard / soft / garrote | hard · soft · garrote thresholding (원어 유지 — 정착 번역어가 없다. 처음 한 번 뜻을 붙인다: 임계값 이하 계수를 0 으로) | 경임계값 · 연임계값 (F2 에서 폐기한 억지 번역어) |
| QRS 보호 | QRS 구간 임계값 완화 | protect_qrs, QRS 보호 |
| Sameni 기법 | 확장 칼만 필터(Sameni 모델) — 「칼만 평활기」로 쓰지 않는다(사용자 결정 2026-11-04). 구현이 순방향 추정 뒤 역방향 평활(EKS)임은 필요한 곳에서 기능 서술로 붙인다 | M05, 칼만, Sameni, 칼만 평활기 |
| 커널 | 가우시안 기저 함수 | 커널 |
| 딥러닝 주력 | 잔차 학습 1D U-Net(Residual U-Net) | M06, Res U-Net |
| 웨이블릿 결합 딥러닝 | 웨이블릿 부대역 U-Net | M08 |
| 출력 = 입력 − 예측 잡음 | 잔차 학습(잡음 추정 후 감산) | 출력단 잔차 |
| L6 | 무잡음 입력 보존항을 추가한 손실 함수 | L6, clean 보존 |
| SNR 조건화 | SNR 조건화(FiLM, feature-wise linear modulation) — §3.1 | 조건화, 동작점 알려 주기, SNR 조건부 특징 변조(출처 미확인 번역어) |
| 없는 파형 생성 | 가성 파형 생성 | hallucination, 지어낸다 |
| 심박 모양 오검출 | 가성 QRS군(위양성 검출 중 평균 박동과의 상관계수 > 0.8) | 심박 모양 가짜 |
| 안전성 프로브 | 가성 파형 생성 검증 실험(박동 삭제 · 3 초 무수축 · 심실조기수축) | 안전성 프로브, P1~P3 |
| 잡음 0 입력 시험 | 무잡음 입력 시 출력 SNR(신호 왜곡 지표) | EXP-C, 왜곡 하한 |
| 산포 | 학습 반복 간 변동(난수 시드 간 표준편차) | seed 산포 |
| 고정 평가 | 고정 평가 집합(모든 모델에 동일 잡음 실현) | 고정 평가 |
| seed 짝 비교 | 동일 시드 대응 비교(대응 t-검정) | 짝지은 Δ |
| 못 잼 | 통계적으로 유의한 차이가 관찰되지 않음 | 못 잼, 못 가림 |
| oracle | 이상적 상한(oracle) | 상한, 천장 |

### 3.1 용어 대조 기록 (A6) — 출처를 확인한 용어

대외 글과 그림에 기술 용어를 새로 넣을 때마다 이 표에 한 줄을 더한다. **출처 칸이 비면 쓰지 않는다**
(`tests/test_academic_style.py::test_term_registry_rows_have_sources` 가 검사한다).

| 원어 | 대외 글의 형태 | 쓰지 않는 형태 | 출처(확인 방법) | 확인일 |
|---|---|---|---|---|
| feature map | 특징 맵(feature map) — 채널 수를 말할 때는 「채널 수」 | 특징 지도 | 국내 CNN 교재 · 강의 자료에서 특징 맵 · 특성 맵 · 피처 맵 병용, 「특징 지도」 사례 없음(웹 검색, 2026-11-04) | 2026-11-04 |

## 5. 점검표 — 기계가 못 보는 것

`check_academic_style.py` 는 어휘(A · B · D1 · D2)만 본다. 원고를 낼 때 아래를 사람이 본다.

- [ ] **A6** 자료(판넬 · 브로셔 · 그림)를 만든 **뒤에** 기술 용어를 전부 뽑아 §3.1 과 대조했나 — 표에 없는 용어는 출처를 찾아 표에 더하거나, 찾지 못하면 원어로 바꾼 뒤 다시 생성한다
- [ ] **C1** 판넬에서 처음 나오는 용어마다 기능 서술이 앞에 있나 — 없으면 해설 노트로 보내고 판넬에서 뺀다
- [ ] **D3** 「-로 해석된다」 자리에 「-이다」 로 단정한 문장이 없나
- [ ] **D4** 각 문단의 첫 문장만 읽어도 요지가 이어지나
- [ ] **E1** 수치마다 데이터 · 조건이 붙었나
- [ ] **F3** 사례 그림에 선정 기준이 적혔나
- [ ] 내부 기록의 결론과 **같은 강도**인가 — 대외 글이 보고서보다 강하게 주장하지 않나(`docs/17_checklists.md` §7)

  꼬리가 긴 범주는 사전으로 다 잡히지 않는다(대조에서 확인).
- 규칙만으로 고르기 어려운 경우를 보이려고 수정 예시(`examples_F.md`)에 「수정하지 않음」 판정도 넣었다.

- 폐기한 시도: 규칙을 먼저 쓰고 후보를 추린 R0 · R1 판. 순서 문제로 폐기했고 산출물은 남기지 않았다
  (이 절이 그 기록이다).
