## 1. 검사 방법

```bash
python3 scripts/check_academic_style.py --file demo/live.html
python3 scripts/check_academic_style.py --file src/components/Plot.tsx
```

- 확장자가 `.html · .htm · .js · .jsx · .ts · .tsx · .vue` 이면 **화면에 보이는 글만** 검사한다.
  주석(`<!-- -->` · `/* */` · `//`)과 `<style>` 은 빼고, HTML 본문은 태그를 지운 글, `<script>` 와 스크립트
  파일은 **문자열 상수**만 본다. `title` · `aria-label` · `placeholder` · `alt` 값(툴팁 · 화면 낭독 글)은 포함한다.
- 값이 비었음을 뜻하는 `—` 한 글자(`<span id="lat">—</span>`)는 표시 관례라 뺀다.
- **기계가 못 보는 것** — 코드 식별자를 그대로 화면에 내보내는 경우(범례 칩이 `M04` 같은 키를 출력),
  조건부로 조립되는 문장의 전체 모양, 관람객 화면과 진단 정보의 구분(U2). §4 점검표로 사람이 본다.

## 2. 화면 글의 규칙 (U) — 95 의 A~F 위에 더한다

| | 규칙 | 예 (전 → 후) |
|---|---|---|
| **U1** | **글의 등급에 따라 종결을 정한다.** 라벨 · 버튼 · 상태값은 **명사구**(종결 어미 없음), 안내문은 **짧은 학술 평서문**(「-이다」 · 「-한다」), 경고 · 오류는 **「대상 + 상태 명사」** | 「못 따라간다」 → **실시간 처리 한계 초과** · 「선 끊김」 → **보드 연결 끊김** · 「브리지에 못 보냈다」 → **브리지 전송 실패** |
| **U2** | **관람객 화면과 진단 정보를 나눈다**(95 C2 의 화면판). 평가자가 해석할 수 없는 진단 지표(프레임 오류 · 재동기화 · 처리 누락 · 도착 간격 · 렌더링 시간 · 소거 비율)는 접힘 영역 「진단 정보」로 옮기고, 관람객 화면에는 **연결 상태 · 처리 지연 · 샘플 손실**만 둔다 | 「지우기 비율 (디버그)」 → 「진단 정보」 안 **소거 구간 비율** |
| **U3** | **기법은 정식 명칭으로**(95 A4). 범례 · 칩 · 선택 목록에 내부 코드(M04 · M_FE · L6)를 출력하지 않는다. 짧은 형태는 §3.2 표 | 범례 칩 「M04 · SWT + QRS 보호」 → **SWT 적응 임계값 처리** |
| **U4** | **내부 기록 번호 · 브랜치 · 파일명을 화면에 쓰지 않는다**(95 A4). 근거가 필요하면 발표자 해설 노트로 | 툴팁 끝의 「(F-55)」 · 「(D-43)」 · 「경위와 수치는 F-27」 → 삭제 |
| **U5** | **무엇이 아닌지보다 무엇인지를 쓴다**(95 B3). 「~이 아니다」로 시작하는 방어 문장 · 대조 수사를 쓰지 않는다 | 「녹음본이 아니다」 · 「지어낸 숫자다」 → **전극 입력 신호를 실시간으로 처리한다** · **기준 신호가 없어 SNR 을 산출할 수 없다** |
| **U6** | **한 화면에 한 용어 · 한 단위 표기.** 같은 화면에서 「초」와 「s」, 「겹치기」와 「겹쳐 보기」를 섞지 않는다. 숫자와 단위 사이는 띄운다(5 s · 85 %) | 「겹치기」 · 「겹쳐 보기」 → **중첩 표시** 하나 |
| **U7** | **경고 기호 뒤는 명사구.** `⚠` 뒤에 구어 서술을 붙이지 않는다 | 「⚠ 선이 뭉쳐 온다」 → **⚠ 수신 간격 불규칙** |
| **U8** | **연구용 시스템임을 밝힌다**(`CLAUDE.md` · `01_design.md` 1.2). 진단 · 모니터링 기기로 읽히는 표현(「환자」 · 「진단」 · 「정상/비정상」 판정 표시)을 쓰지 않는다 | 「LIVE · 연구용 신호처리」 → **LIVE · 연구용 신호처리 시스템** |

95 의 규칙 가운데 화면에서 특히 자주 걸리는 것: **D5**(물음표 없음), **B3**(줄표 `—` 로 잇지 않는다 — 쌍점 ·
쉼표 · 괄호로), **A3**(front-end → 공통 전처리), **A6**(녹음 → 기록 · 저장 신호), **B1**(그린다 · 걷어찬다 → 표시한다 ·
과도 응답을 일으킨다).

### 3.3 범례의 기법 이름 (`LABEL`, 248–253) — U3

범례 칩은 지금 `${n} · ${LABEL[n]}` 로 **내부 코드와 설명을 함께** 출력한다(609 줄). 코드를 빼고 아래 이름만 출력한다.

| 키 | 현재 | 교정안 |
|---|---|---|
| raw | 입력 — 전극에서 온 그대로 (front-end 이전) · 칩 「입력 (잡음)」 | 입력 신호(공통 전처리 이전) |
| M_FE | 공통 front-end (0.5–100 Hz + auto notch) | 공통 전처리(0.5–100 Hz, 조건부 노치) |
| M01 | 대역통과 + notch | 대역통과 · 노치 필터 |
| M02 | Savitzky–Golay | Savitzky–Golay 필터 |
| M03 | DWT | DWT 임계값 처리 |
| M04 | SWT + QRS 보호 | SWT 적응 임계값 처리(QRS 구간 임계값 완화) |
| M05 | Sameni EKS (창 · hop 128) | 확장 칼만 필터(블록 처리) |
| M05S | Sameni EKF · 스트리밍 (미래 144 ms + 고정 지연 평활) | 확장 칼만 필터(스트리밍, 144 ms 고정 지연) |
| M06 | ResUNet1D (딥러닝) | 잔차 학습 U-Net |
| M06L6 | ResUNet1D · clean 보존 손실 | 잔차 학습 U-Net(무잡음 입력 보존 손실) |

칼만 계열은 「칼만 평활기」로 쓰지 않는다(사용자 결정 2026-11-04, LEXICON A3).

### 3.5 하단 해설 (172–180)

관람객용 세 줄과 진단용 한 줄로 나눈다(U2). 「시간축의 주인」 · 「걷어차고」 같은 은유 · 의인화(95 A5 · B1)를 기능 서술로 바꾼다.

| 현재 | 교정안 |
|---|---|
| 회색 구간은 **측정값이 아니다** — 전극이 떨어졌거나(lead-off) 선에서 샘플을 잃어 직전 값으로 채운 자리다. 시간축을 지키려고 채운 것이지 신호가 아니다. | 회색 구간: 전극 분리(lead-off) 또는 수신 손실 구간이다. 시간축 유지를 위해 직전 값으로 채운 표시로, 측정값에 포함되지 않는다. |
| 화면은 **도착한 만큼** 진행한다. 시간축의 주인은 보드이고 PC 벽시계가 아니다 — 두 클럭은 서서히 어긋난다. | 시간축은 보드의 샘플링 클록을 기준으로 하며, 수신된 샘플만큼 진행한다. |
| **처리 밀림**이 0 이 아니면 원인은 선이 아니라 **이 컴퓨터**다 — 방법을 줄이거나 hop 을 키운다. | (「진단 정보」로) 처리 누락 블록은 PC 의 처리 성능 부족을 나타낸다. 표시 기법 수를 줄이거나 hop 길이를 늘린다. |
| **T 파와 다음 P 파 사이가 기울어 보이는 것은 실시간 인과 필터의 것이지 방법의 결함이 아니다.** QRS 가 0.5 Hz 고역통과 필터를 걷어차고, 그 회복이 RR 간격보다 느려 기저선이 다음 박동까지 못 돌아온다. 녹음본(모드 B)은 영위상으로 걸어 이 처짐이 상쇄된다 — 경위와 수치는 **F-27**. | T파와 다음 P파 사이의 기저선 기울기는 실시간 인과 고역통과 필터(0.5 Hz)의 과도 응답에 따른 것이다. QRS군이 일으킨 과도 응답의 회복 시간이 RR 간격보다 길어, 기저선이 다음 박동 전까지 복귀하지 않는다. 저장 신호를 처리하는 벤치마크 화면은 영위상 필터링을 적용하므로 이 현상이 나타나지 않는다. |

## 4. 점검표 — 화면을 고친 뒤

- [ ] `check_academic_style.py --file` 이 화면 파일마다 **0 건**인가
- [ ] 범례 · 선택 목록에 **내부 코드가 출력되지 않는가**(U3 — 검사기가 못 본다. 화면을 띄워 확인)
- [ ] 관람객 화면에 남은 지표가 연결 상태 · 처리 지연 · 샘플 손실뿐인가(U2)
- [ ] 한 화면에서 같은 대상을 같은 말로 부르는가 — 중첩 표시 · 공통 전처리 · 기법(U6 · 95 A3)
- [ ] 새로 넣은 기술 용어가 95 §3.1 용어 대조 기록에 출처와 함께 있는가(A6)
- [ ] 화면을 실제로 띄워 보았는가 — `--replay synth`(명판 「화면 고치기」, `17_checklists.md` §8). 칸을 넘는 라벨이 없는가
