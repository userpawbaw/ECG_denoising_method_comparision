# 36. 선행 연구와 우리 위치

> **왜 이 문서가 생겼나.** D-26(SNR 조건화)을 설계한 뒤 사용자가 외부 조사를
> 가져왔고, **우리가 도달한 설계가 image restoration 분야에 이미 있다**는 것이
> 드러났다. 그것을 숨기지 않고 위치를 적는다 — 졸업과제 보고서에 「우리가
> 처음 고안했다」로 적을 수 없는 부분과, 그럼에도 남는 차별점을 가른다.
>
> **근거 등급 주의**: 이 문서의 논문 수치는 **`[문헌]`, 그중에서도 미검증**이다.
> 이 환경은 외부 망이 막혀 있어 원문을 열지 못했고, 사용자가 가져온 조사 내용을
> 옮긴 것이다. **보고서 본문에 인용하기 전에 원문으로 확인해야 한다.**
> 확인 전까지는 「그렇게 보고돼 있다고 한다」 수준으로만 쓴다.

## 1. 가장 가까운 선행 — DRUNet

Zhang 등의 DRUNet (Deep Residual U-Net, plug-and-play denoiser prior 계열).

| | DRUNet | 우리 `M06` |
|---|---|---|
| 구조 | U-Net + residual block | 같음 |
| 해상도 단계 | 4 | 5 |
| 채널 | 64 / 128 / 256 / 512 | 24 / 32 / 48 / 64 / 96 |
| **단계당 residual block** | **4** | **1** |
| **잡음 세기 조건화** | **noise-level map 을 입력 채널로** | **없음** |
| 차원 | 2D 이미지 | 1D ECG |

**두 칸이 우리가 지금 하려는 것과 정확히 겹친다** — 단계당 블록을 여러 개 쓰는
것(D-27)과 잡음 세기를 알려 주는 것(D-26). **우리 아이디어가 새것이 아니다.**

DRUNet 의 ablation 은 「noise map 을 빼면 나빠진다」, 「residual 을 빼면
나빠진다」까지다. **왜 4 블록인지는 sweep 하지 않았다**고 한다.

## 2. 깊이 배분 — NAFNet · Restormer

| | 보고됐다는 내용 | 우리에게 주는 것 |
|---|---|---|
| NAFNet | 블록 9 → 18 → 36 → 72 로 늘리며 계산량 통제. **36 부근에서 포화** | 깊이에도 포화점이 있다 |
| NAFNet | 단계별 블록 배분이 `[2,2,4,8] → 12 → [2,2,2,2]` 형태 | **해상도가 낮을수록 블록을 많이 둔다** |
| Restormer | 파라미터·FLOPs 를 맞춘 **deep-narrow vs wide-shallow** 비교에서 deep-narrow 우세 | **D-27 의 설계 철학에 선례가 있다** |

**D-27 이 독창적 설계가 아니라는 뜻이다.** 보고서에는 「우리가 depth-width
trade-off 를 고안했다」가 아니라 **「image restoration 에서 보고된 경향이 1D ECG
에서도 성립하는지 통제 실험으로 확인했다」**로 적는다.

## 3. 그래서 우리에게 남는 것

선행이 있다는 것이 이 과제에 **불리하지 않다.** 남는 질문이 더 선명해진다.

| | 선행이 다룬 것 | **우리가 다룰 수 있는 것** |
|---|---|---|
| **조건화 입력** | σ 를 **알려 준다** (합성 AWGN 이라 참값을 안다) | **추정 SNR 로도 되는가.** 실제 장비는 참 SNR 을 모른다. 그리고 **우리 추정기는 실데이터에서 8 배 편향된다**(F-13) — 형식적 확인이 아니라 진짜 어려운 질문이다 |
| **잡음 모형** | 대체로 AWGN | **구조화된 실잡음** — NSTDB 의 bw·em·ma 는 성질이 전혀 다르고 **실측 녹음**이다(D-25). 잡음 *종류*까지 조건화하는 축이 남는다 |
| **실패 현상** | 「조건을 주면 평균적으로 조금 좋아진다」 | **왜 필요한지를 우리 데이터가 보여준다** — 고 SNR 에서 광대역 모델이 **음수**(−2.97)로 무너지고 전담 모델이 **+5 dB** 이긴다(D-26) |
| **평가 축** | PSNR / SSIM | **형태 보존** — `beat_cc` · `qrs_dur_err_ms` · `r_amp_err_pct` 가 이미 있다(F-29 · F-30). SNR 만 올리고 P/QRS/T 를 깎는지 같이 본다 |
| **측정 규율** | 보통 단일 실행 | **F-40 ~ F-42** — 런 간 산포를 재고, 고정 평가로 자를 세우고, 짝지은 검정으로 판정한다. **이 과제의 방법론적 산출물이 여기 있다** |

**마지막 줄이 이 과제의 진짜 차별점일 수 있다.** DRUNet·NAFNet·Restormer 중
어느 것도 「이 차이가 런 간 산포보다 큰가」를 우리처럼 재지 않는다.

## 4. 이야기의 뼈대

선행 발견 이후 보고서의 서사는 이렇게 정리된다.

1. **문제 정의** — 고전 DSP 대 딥러닝, 실사용 SNR 대역에서 무엇을 쓸 것인가
2. **실패 현상 발견** — 광대역 학습 모델이 **고 SNR 에서 신호를 깎는다**
3. **원인 가설** — 동작점을 모른 채 한 벌의 가중치로 타협한다
4. **통제 실험** — 대역 전담(상한) → 조건화, 그리고 대조군으로 저 SNR 전담
5. **개선 구조** — SNR 조건화 ResU-Net. **선행(DRUNet)과 같은 발상이고, 우리는
   그것이 ECG 에서 왜 필요한지와 추정 조건에서도 되는지를 답한다**

「모델 하나 더 만들었다」가 아니라 **「현상 → 가설 → 통제 실험 → 구조」**가 된다.

## 5. 확인해야 할 것 (미검증 목록)

보고서 인용 전에 원문으로 확인한다. 외부 망이 열리는 환경에서 해야 한다.

- DRUNet 의 정확한 채널·블록 구성과 noise-map ablation 수치
- NAFNet 의 블록 수 sweep 수치와 포화 지점
- Restormer 의 deep-narrow vs wide-shallow 비교 조건(파라미터·FLOPs 정합 방식)
- ECG denoising 에서 downstream(QRS 검출·부정맥 분류)을 지표로 쓴 사례

**우리 결과와 맞춰 본 판단** — 「크게 해서 이긴다」는 선행에도 없다. 진전은 **목표**
(diffusion · 손실 형태)와 **정규화 · 학습 세부**에서 왔다. F-55 와 같은 방향이다.

**학습 길이에 대한 단서** — 판당 step 수는 NAFNet 의 1/100 수준이지만, D-23 C 에서
창을 4 배로 늘려 epoch 당 step 이 4 배가 됐을 때 **+0.141 dB** 였다. 「오래 돌리면
오른다」를 우리 데이터는 이미 약하게 반박하고 있다.

**재 본 것 (D-41 → F-57)** — EDSR 식 **정규화 빼기**는 `L1` 총합 −1.35 · 15~20 −1.56 dB
(0/4)로 **손해**였고, **가중치 EMA** 는 val 흔들림을 1/6 로 줄였지만 고정 평가는 같은 환경
기준 ±0.06 dB 로 **효과 없음**이었다 `[측정]`. 둘 다 개선 후보에서 뺀다. 남은 후보(PSNR
손실 · pre-activation · 모델 앙상블 · 시변 잡음 지도 · LayerNorm)는 재지 않았다.
