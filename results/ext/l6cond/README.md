# results/ext/l6cond — D-28 3 번 **2×2 (`L6` × 조건화)**

D-26 이 적은 예측을 친다: **「조건화가 통하면 `L6` 의 이득이 줄어든다」.**
둘 다 「고 SNR 에서 덜 건드리게」 만드는 장치라 겹칠 것이라는 뜻이다.

| arm | 손실 | 조건화 |
|---|---|---|
| `m06_l1` | L1 | ✗ |
| `m06_l6` | **L6** | ✗ |
| `m06_cond` | L1 | **✓** |
| `m06_cond_l6` | **L6** | **✓** |

**네 칸이 한 보관소에 있어야** 짝이 선다. `m06_l1`·`m06_cond` 는 `results/ext/cond`
에도 있지만 결정론이라 값이 같다 (재현 확인을 겸한다).

**핵심 예측은 동등성**이라 `p > 0.05` 로는 못 말한다. 그래서 마진을 **사전에**
선언했다: **|Δ| < 0.5 dB 면 「실질적으로 같다」** (D-28).

## 결과 — seed 4·5 (n=2, **판정 전**)

| | 총합 | −5~0 | 0~5 | 5~10 | 10~15 | 15~20 |
|---|---:|---:|---:|---:|---:|---:|
| `L6` 이득, 조건 없음 (`m06_l6 − m06_l1`) | **+2.040** | +0.43 | +0.97 | +1.52 | +2.60 | **+4.28** |
| `L6` 이득, 조건 있음 (`m06_cond_l6 − m06_cond`) | **+1.156** | +0.31 | +0.64 | +0.94 | +1.63 | **+1.90** |
| **상호작용** | **−0.883** | | | | | |

방향은 예측대로다 — **조건화가 있으면 `L6` 의 이득이 줄어든다.** 다만 크기는
**아래 편향을 걷어내고** 봐야 한다.

**⚠ 이 seed 들에서 상호작용은 과장된다.** F-44 의 기제다. seed 4·5 에서
`m06_l1` 은 자기 6-seed 평균보다 **0.466 낮고**(→ 조건 없는 쪽 이득이 부푼다),
`m06_cond` 는 **0.061 높다**(→ 조건 있는 쪽 이득이 깎인다). 둘 다 상호작용을
**더 음수로** 민다. 대략 되돌리면 **−0.36 근처**이고, 그 값은 **동등 마진
(0.5) 안**이다. 즉 K=8 에서 판정이 「다르다」에서 「같다고 볼 만하다」로
뒤집힐 수 있다. **지금 판정하지 않는다.**
