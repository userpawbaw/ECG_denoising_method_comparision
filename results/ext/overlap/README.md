# results/ext/overlap — **두 환경이 같은 Δ 를 내는가**

F-44 를 쓰다 구멍이 하나 나왔다. **환경이 seed 묶음과 완벽히 겹친다** —
D-27 의 seed 0~3 은 Colab T4, 4·5 는 이 컨테이너 CPU 다. 「한 seed 의 모든
arm 은 같은 환경」(F-41)은 짝지은 차분을 지키지만, 그 대가로 **환경×arm
상호작용을 seed 효과와 구분할 수 없게** 만든다. 그리고 D-27 에서 Δ 의 부호가
갈린 지점이 하필 그 환경 경계였다.

그래서 **seed 0 의 네 arm 을 CPU 에서 한 번 더** 돌렸다. `results/ext/depth`
에 있는 같은 seed 0(T4)과 Δ 를 직접 견주면 상호작용이 그대로 나온다.

**두 환경을 합치는 모든 판정이 여기 얹혀 있다** — F-44 의 K=6, 조건화의 K=6,
앞으로의 2×2 K=8.

## 결과 — 합쳐도 된다 `[측정]`

| arm | Δ (T4) | Δ (CPU) | 차이 |
|---|---:|---:|---:|
| `deep2` | −1.141 | −0.958 | +0.183 |
| `deep3` | −0.429 | −0.373 | +0.055 |
| `deep4` | −0.198 | −0.528 | **−0.329** |

**셋 다 부호가 같고**, 차이의 평균은 −0.030 이다. 최대 |차이| 0.329 는 하드웨어
흩어짐 기준(sd 0.184)의 1.8 배지만 **체계적 방향이 없다**(+, +, −). 즉
「T4 에서는 깊이가 손해, CPU 에서는 이득」 같은 상호작용은 **없다.**

**D-27 에서 seed 4·5 가 양수였던 것은 환경 탓이 아니다** — F-44 가 적은 대로
세 Δ 가 기준 항을 공유하고 그 seed 들의 기준값이 낮았기 때문이다. 여기서
같은 seed 0 을 CPU 로 돌려도 Δ 는 그대로 음수였다.
