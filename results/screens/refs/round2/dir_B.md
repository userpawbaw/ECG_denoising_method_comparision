## 0.5 **레퍼런스 없음** — 이 라운드는 원본 장면을 하나도 안 봤다 (UO-6 추기, 2026-09-20)

사용자 질문 「레퍼런스, 원본 DNA 는 깃허브 문서에만 포함했어?」 `[대화]` 로 드러난 것이다.
**그렇다.** 아래 후보 다섯에 **URL 0 개 · 레퍼런스 카드 0 장 · L1 캡처 0 장**이다.

| 이 라운드가 읽은 외부 자료 | 무엇 |
|---|---|
| Superdesign GitHub 문서 9 개 (150 KB) | **방법**(절차 규칙). 시각 레퍼런스가 **아니다** |
| `02_benchmark` §13 골격 메뉴 | 장치는 `GRAPHIC.md` 에서 빌렸지만 **내용은 우리 어휘로 새로 썼다** |
| 외부 장면 | **없다** |

**왜 없나** `[측정]`: 이 환경에서 시각 레퍼런스로 가는 길이 전부 막혔다 —
`en.wikipedia.org` · `upload.wikimedia.org` · `commons.wikimedia.org` · `web.archive.org` ·
`earthquake.usgs.gov` · `eyes.nasa.gov` · `dood.al` · `*.flourish.studio` **전부 `000`**,
`api.superdesign.dev` 는 `403`. 열리는 것은 `raw.githubusercontent.com` 뿐이라 **문서만** 읽혔다.
Flourish MCP 는 템플릿 64 개를 주지만 **이름과 한 줄 설명**뿐이고 `showcase_url` 은 `000` 이다.

**그래서 후보 다섯은 무엇에 기대고 있나** — 원본 대신 적는다:

| 후보 | 기댄 것 | 이것이 왜 카드가 아닌가 |
|---|---|---|
| C1 접촉 인화 격자 | 사진의 **contact sheet** 라는 형식(기억) + `demo_bank` 의 7×7 구조(코드) | 실제 장면을 **안 봤다.** 「어디를 볼지」도 Imitation Distance 도 잴 수 없다 |
| C2 중첩 한 축 | 차이를 면적으로 보이는 관습(기억) | 같음 |
| C3 분할 | **A2**(라운드 ①) | A 의 후보이지 원본이 아니다 |
| C4 레인 스택 | **A4** → 그 뿌리는 REF-06 USGS 헬리코더 | 카드가 `round1/` 에 있다. **이 라운드가 본 것은 아니다** |
| C5 액자 | **REF-07** 스플릿플랩의 「드물고 확실하게」 | 같음 |

**즉 다섯 중 셋은 A 의 카드를 한 단계 건너 쓴 것이고, 둘은 원본이 아예 없다.**
이것이 이 라운드의 한계이며, 라운드 ③(로컬 Superdesign · `extract-website`)이 되돌릴
변수다. **판정 단계로 넘어가기 전에 사용자가 이 사실을 알고 있어야 한다.**

## 3. 후보 다섯

### C1 — 「**골라 보여 준 게 아니라고 먼저 말하는** 화면」 · 골격 ⑤

7 잡음 × 7 SNR **49 타일을 한꺼번에** 깐다(축 둘은 번갈아). 타일마다 **그 조건의 실제 한 박동**.
멀리서는 값이 아니라 **얼룩의 지도**로 읽힌다 — 한쪽 모서리는 거칠고 반대쪽은 매끈하다.
스윕 커서가 **한 줄씩** 훑고 지나간 타일만 입력→출력으로 갈린다.

| | |
|---|---|
| **주장** | 「이건 한 장면이 아니라 전부다」 — 규모·전수 |
| **바꾸는 것** | 골격(격자). 시간축이 **타일 안에서만** 흐른다 |
| **그대로 두는 것** | 타일 안의 파형 기하 · 50 mm/s · 10 mm/mV · 격자 규약 · 무채 팔레트 · 「재생」 표기 |
| **3 m 첫인상** | 「거친 쪽에서 매끈한 쪽으로 가는 지도」. **값은 안 읽힌다 — 그게 목표다** |
| **기하** `[측정]` | 타일 **246.6 × 117.1 px = 1.30 s.** ±1.0 mV 가 타일 높이의 **65 %**, ±1.5 mV 는 **97 %** → **1.5 mV R 파는 여백을 다 먹고 이웃 타일을 침범한다.** 이 골격의 검증 지점이 여기다 |
| **위험** | ① 타일이 1.3 s 라 **P 파가 안 보인다** — 「심전도」가 아니라 「잡음 패턴」으로 읽힐 수 있다 ② 격자가 「골라 보여 준 게 아니다」가 아니라 **「복잡하다」**로 읽힐 수 있다 |
| **A 가 보이는 자리** | **없다.** A 에도 B 에도 없던 골격이다 |

### C2 — 「**차이가 어디서 나는지 한 자리에서** 보이는 화면」 · 골격 ④

한 레인에 입력과 출력 **둘만** 겹친다. **색으로 가르지 않는다** — 두 선이 같은 자리면 한 선으로
보이고, 벌어진 구간만 그 사이가 **회색 면으로 채워진다.** 차이가 선이 아니라 **면적**이 된다.

| | |
|---|---|
| **주장** | 「차이는 여기서만 난다」 |
| **바꾸는 것** | 두 계열을 한 축에 겹치고, 차이를 **색이 아니라 면적**으로 |
| **그대로 두는 것** | 기하 · 속도 · 단위 · 무채 팔레트 · 「재생」 표기 · 참값은 여전히 안 깐다 |
| **3 m 첫인상** | 「한 줄인데 군데군데 뚱뚱하다」 — 뚱뚱한 곳이 잡음 |
| **기하** `[측정]` | 레인 1726 px = 9.1 s. ±1.0 mV 폭 75.9 px 안에서 면적이 생긴다 |
| **위험** | ① **임상 오독이 크다** — 넓어진 QRS 는 실제 진단 소견이다. 「뚱뚱함」을 파형의 일부로 읽으면 우리가 금지한 진단 암시에 걸린다 ② Reference/Difference 의 의미를 바꾸는지 **LOW 구역 규약과 먼저 대조**해야 한다 |
| **A 가 보이는 자리** | **없다.** 중첩은 A·B 어디에도 없다 |

### C3 — 「**같은 순간임을 구조로 증명하는** 화면」 · 골격 ③

화면을 좌/우로 가른다. 왼쪽 입력, 오른쪽 출력, **같은 4.4 s**. 두 판 사이를 **세로 격자선 하나가
관통해** 두 판의 같은 x 가 같은 시각임을 선으로 못 박는다.

| | |
|---|---|
| **주장** | 「전후가 아니라 **같은 순간의 두 읽기**다」 |
| **바꾸는 것** | 보이는 시간을 반으로 줄이고 **폭을 산다** |
| **그대로 두는 것** | **50 mm/s 는 안 바꾼다** — 속도가 아니라 보이는 시간이 주는 것이다. 게인 · 격자 · 색 · 표기 |
| **3 m 첫인상** | 「같은 모양 둘, 오른쪽이 깨끗」 |
| **기하** `[측정]` | 반쪽 **843 px = 4.45 s.** 60 bpm 에서 **4 박동** |
| **위험** | ① 부정맥·간헐 잡음이 한 화면에 안 들어온다 ② 미니맵·판정 문장이 **9.1 s 를 전제로** 쓰여 있다 — 전부 다시 계산해야 한다 |
| **A 가 보이는 자리** | **있다.** A2「한 커서, 두 레인 · 같은 x」의 주장과 같다. 골격만 다르다(세로 갈림 → 좌우 갈림) |

### C4 — 「**어디서부터 못 건지는지** 보이는 화면」 · 골격 ②

SNR 7 단을 동시에 쌓는다. 각 단은 그 SNR 의 **실제 장면**이고, 각 단에 **입력이 아니라 출력만**
그린다. 위에서 아래로 SNR 이 낮아지고, **어느 단부터 파형이 무너지는지**가 세로로 보인다.

| | |
|---|---|
| **주장** | 「이 방법은 **여기까지** 건진다」 — 성능의 한계선 |
| **바꾸는 것** | 7 단 동시. 그리고 **입력을 안 그린다**(출력만) |
| **그대로 두는 것** | 각 단의 기하 · 속도 · 단위 · 무채 |
| **3 m 첫인상** | 「위는 심전도 모양, 아래로 갈수록 뭉개짐 — **경계가 보인다**」 |
| **기하** `[측정]` | 7 × 75.9 = **531.0 px** 신호분. 820 px 안에서 단당 117.1 px, 여백 41.3 px ✓ |
| **위험** | ① **B4 가 기각된 함정 바로 옆**이다 — 「입력 SNR 이 바뀌는 것」을 「제거 성능」으로 읽는 것. 출력만 그려 혼동을 줄였지만, 대신 **왜 아래가 나쁜지의 원인이 화면에 없다** ② 원인을 적으려면 단마다 SNR 숫자가 필요한데 **3 m 에서 그 숫자는 안 읽힌다**(§10) ③ 쌓인 줄이 **연속된 한 기록**으로 읽히면 거짓 |
| **A 가 보이는 자리** | **있다 — 가장 짙다.** A4「조건 사다리」와 같은 골격이고, 다른 것은 **「출력만 그린다」** 한 가지다 |

### C5 — 「**기록이 계속 갈리고 있음을 알리는** 화면」 · 골격 ⑥

위·아래 **두 가로 띠만** 그린다 — **세로 구간은 안 그린다**(그리면 시간축이 세로가 되어 R-A 위반).
위 입력, 아래 출력, **같은 10 s**. 가운데 600 px 는 비었고 거기에 **문장 하나**.
**커서가 없다** — 두 기록은 이미 다 그려진 정지 상태고, 6 s 마다 **장면이 통째로 갈린다.**
움직임은 그 갈림 하나뿐이다.

| | |
|---|---|
| **주장** | 「여기 기록이 있고, 계속 새 기록으로 갈린다」 — 존재감 |
| **바꾸는 것** | 움직임을 **드물고 확실하게**. 연속 스윕을 버린다 |
| **그대로 두는 것** | 기하 · 그려진 결과의 50 mm/s 스케일 · 색 · 표기 |
| **3 m 첫인상** | 「가운데 글씨, 위아래로 심전도가 액자처럼」 + 6 s 마다 **전부 바뀐다** |
| **기하** `[측정]` | 띠 각 1726 px = 9.1 s, 높이 110 px(신호 75.9 + 여백 34.1). 가운데 600 px → 69 px 문장 두 줄 + 여백 ✓ |
| **위험** | ① 커서가 없으면 **정지 화면/고장**으로 읽힌다 — B3 이 기각 직전까지 간 그 위험이다 ② 6 s 는 지나가는 사람에게 길다 ③ 위/아래가 **시간상 연속**으로 오독될 수 있다(실제론 같은 10 s) |
| **A 가 보이는 자리** | **있다.** 「드물고 확실하게」는 REF-07(스플릿플랩)에서 온 원리다 |
