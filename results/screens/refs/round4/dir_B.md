### 1.2 어떻게 좁혔나 — 태그로 먼저 자르고, 그 다음 열었다

`minimal.gallery` 는 항목마다 **외부 링크**(`a.site-button`)를 들고 있어서, 태그별 목록에서
**실제 사이트 URL 을 한 번에 뽑을 수 있다.** 빈 칸 셋에 맞는 태그만 골라 훑었다:

| 노리는 칸 | 훑은 태그 |
|---|---|
| ③ 격자 | `catalogue` · `online-gallery` · `directory` · `photography` · `type-foundry` |
| ④ 겹침 | `science` · `research` · `environmental` · `documentary` |
| ⑤ craft | `art` · `museum-gallery` · `animation` · land-book **Motion** 갈래 |

그렇게 약 **150 개 항목의 이름과 URL** 을 보고, 그중 **10 개를 열었다.** 한 사이트에 30~60 초.

### REF-03 — Antikythera, *Hemispherical Stacks*, **스크롤한 목차 화면**

| | |
|---|---|
| 출처 · URL | Antikythera Journal · https://hemstacks.antikythera.org/ |
| **어디를 볼지** | **가운데 두 열 목차만.** 열아홉 줄이 전부 **배경 호박색 위에 호박색**으로 겨우 보이는데, **정확히 한 줄 — `IRIS LONG / UNDERGROUND INTELLIGENCE` — 만 흰색이다.** 그 다음 왼쪽 초록을 본다: 흰 본문 한 문단이 그 줄에 대응한다. 마지막으로 **없는 것**을 본다 — **하이라이트 상자도, 배경 띠도, 호버 칩도 없다.** 스크롤하면 흰 줄이 다음 줄로 옮겨 가고 앞 줄은 **제자리에서 배경으로 가라앉는다** |
| 잊히지 않는 순간 | **선택 표시가 아무 형태도 없다.** 대비 하나로 끝난다 |
| 기제 | 전면 이미지를 **한 색조로 눌러** 바닥 층으로 만들고, 그 위에 목록을 **전부 임계 근처**로 얹는다. 신원은 **어느 것이 잉크인가**로만 갈린다. 색상(hue)이 신원을 나르지 않는다 |
| 기대 감각 | 「전부 거기 있는데, 지금은 이것을 보고 있다」 |
| 프로젝트 번역 | **C2(중첩 한 축, 골격 ④)의 없던 원본이 여기다.** UD-11 이 지적한 「색만으로 신원이 갈리면 색각 위반」의 답이 나온다 — 7 계열을 한 레인에 겹치되 **전부 격자 밝기대로 깔고 지금 것 하나만 `ink`(paper 위 7.50:1)** 로. **hue 를 0 개** 쓰고 겹침을 해낸다 |
| 복사 금지 | 호박색 듀오톤 · 지하 동굴 일러스트 · 모노스페이스 전면 조판 · 검정 카드 |
| Imitation Distance | **4** — 「층 위의 목록, 정확히 하나만 잉크, 나머지는 배경 색조로」 원리 하나 |

### E1 — 「**실험 전체가 한 화면에 있다**고 보이는 화면」 · 골격 **⑤ 접촉 인화 격자** (REF-02 · REF-01 · REF-06)

98 장면을 10×10 타일로 **한꺼번에**. §13 기하: 타일 ≈**185 px = 0.98 s** — 타일 하나가 **한 박동**.
세 원본이 이 후보의 세 부분을 각각 댄다:

- **격자를 먼저 긋는다**(REF-02) — 헤어라인이 **빈 칸도 뚫고** 끝까지 간다. 98 장이 다 안 차도 격자는 100 칸이다.
- **라벨은 타일 위 규칙선에**(REF-02) — `SNR 5 dB · 근전도` 가 파형을 **한 번도 안 가린다.**
- **다가온 타일만 제자리에서 어두워지고**(REF-01) 그 **안에** `+11.8 dB` 가 뜬다. 격자는 안 흐른다.
- **활성 타일은 커지지 않는다**(REF-02) — 줄이 하나 늘 뿐이다.
- **발산한 장면은 격자 밖 아래 줄로**(REF-06) — 색·배지가 아니라 **자리**로 표시한다.

### E3 — 「**전후가 같은 자리에 층으로 쌓여 있는** 화면」 · 골격 **메뉴에 없다 → ⑧ 제안: 떠 있는 패널 + 가운데 대상** (REF-05)

왼쪽 ≈340 px 에 **층 목록** — `출력 / 입력 / 참값 / 기록지`, 각 줄에 **썸네일**과 불투명도.
가운데가 레인 하나. 무엇이 **위**인지가 목록으로 보이고 그 목록이 곧 조작이다.
UD-11 이 계약으로 박은 **Reference·Difference 가 끄고 켜는 층**이 된다.

기하 `[측정]`: 원본 비율을 1920 에 옮기면 좌우 패널 ≈343 px 씩, 가운데 **1234 px = 325.3 mm →
50 mm/s 에서 6.5 s.** §13 ① 의 9.1 s 보다 **2.6 s 짧다** — 그만큼을 패널이 가져간다.

| | |
|---|---|
| 바꾸는 것 | 비교를 **나란히(가로)에서 위아래(z)로.** 그리고 z 순서를 **읽을 수 있게** 노출한다 |
| 그대로 두는 것 | 같은 y 축 · 같은 순간 · 기하 · 단위 · 「재생」 표기 |
| 3 m | 「가운데 심전도 하나, 양옆에 어두운 판 둘」 |
| 위험 | ① **지금 무엇이 보이는 중인지가 3 m 에서 안 보인다** — 상태가 패널 안 작은 글자에만 있다 ② attract 는 **아무도 안 만진다.** 층 조작은 다가온 사람 것이고 3 m 용으로는 **층이 저절로 바뀌는** 장치가 따로 필요하다 ③ **보이는 시간이 6.5 s 로 준다** — 9.1 s 를 전제한 문장·미니맵이 안 맞는다(§13 이 ③ 분할에 적은 것과 같은 종류의 비용) ④ 골격이 메뉴 밖이다 — **⑧ 로 넣을지는 이 문서가 정하지 않는다** |
| 빌린 원리 | REF-05 「z 순서를 목록으로 노출 · 층마다 썸네일 · 층마다 불투명도」 · REF-05 「가장자리의 얇은 등록 표시 — 작업물이 아니라 작업대라고 말한다」 |

### E4 — 「**일곱 줄을 겹쳐 쌓아 세로 예산을 이기는** 화면」 · 골격 **② 레인 스택** (REF-04)

D2(라운드 ③)·C4(라운드 ②)가 쓴 골격이지만 **원리가 다르다.** 저쪽은 줄을 **나눠** 넣었고
이쪽은 **물려** 넣는다. 레인은 **불투명 paper 판 + 1 px lattice-bold 규칙선**, 각짐(radius 0),
제목은 규칙선 위. 위 레인이 아래 레인의 **아래쪽**을 가린다.

**잰 것** `[측정]` — 이 후보의 값은 이것 하나다:

| | 안 겹칠 때 | **40 % 물릴 때** |
|---|---|---|
| 줄 높이 | ±1.0 mV = **75.9 px** | ±1.5 mV = **113.8 px** |
| 7 줄 합 | 7 × 75.9 = **531.3 px** | 6 × 68.3 + 113.8 = **523.5 px** |

→ **같은 531 px 예산에서 각 줄이 ±1.0 mV 에서 ±1.5 mV 로 커진다.** 겹침이 사 오는 것이 이것이다.

| | |
|---|---|
| 바꾸는 것 | 줄 사이 여백을 **음수로.** 겹침을 감추지 않고 **경계선으로** 읽히게 한다 |
| 그대로 두는 것 | 7 조건 · 같은 10 s · 같은 y 축 · 기하 · 단위 |
| 3 m | 「일곱 줄이 서로 물려 쌓여 있다」 — 물린 자리가 **두께**를 만든다 |
| 위험 | **이 라운드에서 제일 위험한 후보다.** 글은 잘려도 「더 있다」로 읽히지만 **파형은 잘리면 「작다」로 읽힌다.** 가려지는 쪽이 R 피크면 **진폭 오독**이고 이건 미감이 아니라 **데이터 거짓말**이다 — LOW 구역. 최소 조건 둘: ① 가려지는 쪽을 **기준선 아래**로 고정 ② 가려지는 양을 **0.5 mV 이내**로 못 박기. 이 둘을 못 박으면 이 후보는 안 된다 |
| 빌린 원리 | REF-04 「겹침을 감추지 않는다 — 맨 위 한 장만 온전하고, 잘린 것이 곧 '더 있다'」 · REF-04 「불투명 판 + 1 px 규칙선 + radius 0, 제목은 규칙선 위」 |

### E5 — 「**크롬이 기록지 위에 떠 있는** 화면」 · 골격 **① 전면 한 레인** (REF-01 · REF-05)

레인이 화면 전체(**1726 px = 9.1 s**)를 먹고, 제목·칩·판정이 **알약으로 그 위에 뜬다.**
기록지가 알약 **아래로 이어진다** — 크롬이 세로 예산을 **0 px** 쓴다.
좌우 맨 끝에 **얇은 등록선** 하나씩(REF-05).

회수했고, 이쪽은 **위로 띄워서** 회수한다. 나란히 놓고 보면 갈린다.

### 이 라운드가 드러낸 것 (판정 아님 — 관찰)

- **§14 의 `[측정]`이 환경에 딸려 있었다.** 「`minimal.gallery`·`land-book`·`behance` 전부 `000`」은
  **클라우드 세션의 사실**이고 로컬에선 셋 다 200 이다. `[측정]` 태그에 **어느 환경에서 쟀는지**가
  같이 붙어야 한다는 뜻이다 — UF 후보다.
- **③ 격자와 ④ 겹침 칸이 채워졌다.** C1 은 REF-02·REF-01·REF-06 을, C2 는 REF-03 을 원본으로 갖게 됐다.
  UO-6 이 적은 「원본 없이 나온 자리」 둘이 메워졌다.
- **⑤ craft 칸은 절반만 채워졌다.** 갤러리 상위작에서 기대한 「wow 3 초」는 **거의 다 스크롤이 몬다** —
  `vizcom` 도 그랬다. **attract 에는 스크롤이 없다.** 갤러리 허브가 craft 를 많이 갖고 있어도
  그중 **관람객이 안 만지는 화면에 옮길 수 있는 것**은 얇다. 이건 허브의 한계가 아니라
  **우리 구역(attract)의 성질**이고, 다음 라운드가 노린다면 **시간이 모는 전환**을 가진 소스
  (전시·키오스크·사이니지, §8.2.1 의 ⑥ 칸)로 가야 한다.
- **골격 메뉴에 또 없던 것이 나왔다** — E3 의 「떠 있는 패널 + 가운데 대상」. 라운드 ③ 의 ⑦ 에 이어 둘째다.
  **⑧ 로 넣을지는 이 문서가 정하지 않는다.**
- **REF-04 가 우리에게 준 것은 원리가 아니라 위험이다.** 겹침을 감추지 않는 것은 글에서는
  성립하고 **파형에서는 거짓말이 될 수 있다.** 그 선(기준선 아래 · 0.5 mV 이내)을 이 문서가
  처음 적었다 — 재 볼 값이 생겼다는 뜻이다.
