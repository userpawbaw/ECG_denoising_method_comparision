# 학술 서술 수정 예시 — 최종 규칙(F) 적용

검토 후보(`candidates_F.csv`)에서 출처 · 범주가 고르게 섞이도록 고른 예시다. 수정안은 `rules_F.md` 의 교정 지침을 따랐고, 수치는 원문 · 보고서 요약표 · 발표자 해설 노트에서 그대로 옮겼다. **원문은 아직 고치지 않았다** — 판정 뒤에 반영한다.

## 예 1. 판넬 · `build_panel.py:257` · D1 D3 D4

- **원문** — • 딥러닝의 성능 향상은 모델의 구조나 규모보다 학습 목표(손실 함수)의 설정에서 비롯되었다
- **수정안** — 신경망 기법에서 구조 · 규모를 바꾼 시도는 SNR 개선량을 유의하게 높이지 못하였고, 유의한 증가는 손실 함수 변경과 SNR 조건화에서만 관찰되었다.
- **판단** — D1 딥러닝 → 신경망 기법. D3 성능 → SNR 개선량. D4 「비롯되었다」(원인 단정)를 관찰 서술로 바꿨다. 같은 판넬의 그림 설명(249 행)이 SNR 조건화도 유의하다고 적고 있어 함께 넣었다 — 원문은 이 점에서 판넬 안에서 어긋난다.

## 예 2. 판넬 · `build_panel.py:243` · D1 D4

- **원문** — 기저선 변동은 공통 전처리로 제거되며, 임펄스 잡음은 딥러닝에서만 제거된다.
- **수정안** — 기저선 변동은 공통 전처리만으로 제거되었고, 임펄스 잡음은 실제 적용 가능한 기법 중 신경망 기법에서만 제거되었다.
- **판단** — 이상적 상한(oracle)도 임펄스 잡음을 일부 줄이므로(보고서 8 장 요약표) 「~만」의 범위를 「실제 적용 가능한 기법 중」으로 한정했다.
