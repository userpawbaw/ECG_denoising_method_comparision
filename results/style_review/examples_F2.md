# 학술 서술 수정 예시 — 판정 반영(F2)

사용자 판정 16 건을 반영한 결과(§1)와, 판정받지 않은 후보 · 보고서에 남은 후보에 대한 새 수정안(§2)이다.
수정안의 수치는 원문 · 원자료에서 그대로 옮겼다. §2 는 **아직 원문에 반영하지 않았다** — 판정 뒤에 반영한다.

## 1. 판정을 반영한 결과

### 판넬 · 비고(SWT 카드)

- **이전** — 실측 기록의 최적 설정: 임계값 이하 계수 제거(경임계값 처리), QRS 구간 완화 미적용.
- **반영 문안** — MIT-BIH 실측 기록에서는 hard thresholding(임계값 이하 계수 제거, 초과 계수 유지)이 최적이었다.
- **근거** — 판정 「경임계값은 어색하다 · 원어를 쓰라」 「QRS 구간 완화를 설명하지 않을 거면 빼라」 → F2 의 A1 · A6 · C6. QRS 완화는 해설 노트로 옮겼다.

### 판넬 · 고찰

- **이전** — 잔차 학습 구조의 딥러닝은 가성 파형 생성이 가장 적었다.
- **반영 문안** — 비교한 기법 중 잔차 학습 구조의 딥러닝 기법들의 가성 파형 생성 에너지가 가장 낮았다(MIT-BIH, 대역통과 필터 대비 2.8~3.9배 낮음).
- **근거** — 앞선 예시의 「잔차 학습 신경망의 … 가장 낮았다」는 수치 귀속이 틀렸다. 2.8~3.9 배는 딥러닝 세 기법 전체의 범위이고, 잔차 U-Net 하나는 최저가 아니다(07_safety_probe_d1). 원문 뜻대로 「기법들」로 바로잡았다. 「딥러닝」은 판정대로 유지.

### 판넬 · 그림 6 설명

- **이전** — 기저선 변동은 공통 전처리로 제거되며, 임펄스 잡음은 딥러닝에서만 제거된다.
- **반영 문안** — 기저선 변동은 공통 전처리만으로 제거되었고, 임펄스 잡음은 실제 적용 가능한 기법 중 딥러닝에서만 제거되었다.
- **근거** — 판정 「딥러닝을 신경망으로 바꿀 근거가 없다」 → F2 D1 지침. 판정 「공통 전처리를 bandpass + notch 로 풀어라」 → 판넬 첫 등장(작품 개요)에 「공통 전처리(0.5~100 Hz bandpass, 전원선 잡음 검출 시 notch)」로 정의.

### 판넬 · 작품 내용

- **이전** — 단일 조건에서 기법의 우열을 판정하는 대신, 잡음 종류와 입력 SNR에 따라 …
- **반영 문안** — (바꾸지 않음)
- **근거** — 판정 「SNR 을 굳이 바꿀 이유는?」 → F2 C5: 분야 공통 약어(SNR · dB · ECG · QRS)는 판넬에서도 풀지 않는다.

### 보고서 · 1.3 연구 질문 표

- **이전** — wavelet을 **전처리**로 쓰는 것과 **신경망의 표현공간**으로 쓰는 것 중 무엇이 나은가?
- **반영 문안** — wavelet을 전처리로 쓰는 것과 신경망의 표현공간으로 쓰는 것 중 무엇이 나은가?
- **근거** — 판정 「** 강조는 AI 출력물의 전형」 → F2 B3 등급 1. 보고서 전체에서 굵은 글씨 1,500 쌍을 지웠다. 연구 질문은 질문형을 허용한다(B8 제외).

### 판넬 · 고찰 · 카드 · 그림 · 브로셔

- **이전** — (나머지 10 건)
- **반영 문안** — 검토판의 수정 예시대로 적용
- **근거** — 그림 8 · S17 제목, 카드 ② 장점, 카드 ③ 손실식 · 한계, 고찰 셋째 · 넷째 항목, 브로셔 그림 2 · 작품 목표, S17 행 이름, S20 부제. 판넬 · 브로셔를 다시 만들어 넘침이 없는 것을 확인하였다.

## 2. 새 수정안 (F2 규칙 적용, 판정 전)

### 예 1. 판넬 · `build_panel.py:219` · D2 D3

- **원문** — 저 SNR 구간과 임펄스 잡음에서 성능이 높고, 가성 파형 생성이 가장 적다.
- **수정안** — 입력 SNR 13 dB 미만 구간과 임펄스 잡음에서 SNR 개선량이 공통 전처리보다 높고, 가성 파형 생성 에너지가 고전 필터 · SWT · 칼만 평활기보다 낮다(MIT-BIH, 대역통과 필터 대비 약 3.2 배 낮음).
- **판단** — [사실 오류] 이 카드는 잔차 U-Net 하나를 설명하는데, 박동 삭제 조건에서 Dilated ResNet(0.0109) · SWT 직렬 결합(0.0113)이 잔차 U-Net(0.0137)보다 낮아 「가장 적다」가 성립하지 않는다(07_safety_probe_d1). 3.2 배 = 0.0437 / 0.0137. 판정 전이라도 고치기를 권한다.
